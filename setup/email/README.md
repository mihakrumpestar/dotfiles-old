# Email

Betterbird + Birdtray

Theme:

- Dark/Black theme

Extensions:

- Attachment Viewer: view in a tab, slideshow
- Copy Address
- Dark Reader
- DeepL selected text
- DKIM Verifier
- Emoji
- Grammar and Spell Checker — LanguageTool
- ImportExportTools NG
- keepassxc-mail: Set to auto submit
- Minimize on Close
- PrintingTools NG
- Quicktext
- Send Later
- Shrunked Image Resizer: install manually from [here](https://github.com/memeller/shrunked/releases)
- Web Translate
- Signature Switch

Alternatives:

- [Claws Mail](https://www.claws-mail.org/index.php): could not authenticate with my email provider
- [Evolution](https://wiki.gnome.org/Apps/Evolution): can't build
- [Kontact](https://kontact.kde.org/): no multilanguage typing correction

Extra resources:

- Thunderbird with [keepassxc-mail](https://github.com/kkapsner/keepassxc-mail)
