# Email

Betterbird + Birdtray

Theme:

- Dark/Black theme

Extensions:

- Attachment Viewer: view in a tab, slideshow
- Copy Address
- Dark Reader
- DeepL selected text
- DKIM Verifier
- Emoji
- Grammar and Spell Checker — LanguageTool
- ImportExportTools NG
- keepassxc-mail: Set to auto submit
- Minimize on Close
- PrintingTools NG
- Quicktext
- Send Later
- Shrunked Image Resizer: install manually from [here](https://github.com/memeller/shrunked/releases)
- Web Translate
- Signature Switch

Alternatives:

- [Kmail](): does not start under nix-env
- [Geary](): nice basic email client, can't directly edit 'From' field only from identities, no LanguageTool support (but does have the system spellcheck), uses secret storage, no tray icon
- [Claws Mail](https://www.claws-mail.org/index.php): old UI, could not authenticate with my email provider
- [Evolution](https://wiki.gnome.org/Apps/Evolution): has system spellcheck, no LanguageTool, requires a lot og GNOME stuff so it is not usable
- [Kontact](https://kontact.kde.org/): no multilanguage typing correction
- [Balsa](https://pawsa.fedorapeople.org/balsa/index.html): can't connect my provider as IMAP refuses to work or crashes/freezes app when trying to apply settings, uses secret storage

Extra resources:

- Thunderbird with [keepassxc-mail](https://github.com/kkapsner/keepassxc-mail)
